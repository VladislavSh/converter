# Flux — конвертер валют

Лёгкий PWA-конвертер фиатных валют и криптовалют без сборки и зависимостей.

- Ввод в любую строку — пересчёт всех остальных; поддержка выражений (`120*3+15`, `10%`, скобки)
- 160+ фиатных валют (exchangerate.fun, запасной источник open.er-api.com) и 18 криптовалют (CoinGecko)
- Добавление/поиск валют в шторке, перетаскивание для сортировки, копирование суммы
- Тёмная и светлая темы, RU/EN, анимированный загрузочный экран
- Офлайн-режим: курсы кешируются в `localStorage`, оболочка — в Service Worker
- Устанавливается как приложение (manifest + SVG-иконка)

## Запуск

Любой статический сервер, например:

```
npx http-server -p 5173 -c-1
```

и откройте http://localhost:5173. Для GitHub Pages достаточно залить содержимое репозитория.

## Структура

```
index.html            разметка, лоадер, шторка выбора валют
css/style.css         дизайн (glassmorphism, aurora-фон, темы)
js/currencies.js      метаданные валют и криптовалют
js/app.js             логика: курсы, расчёт, рендер, drag & drop
sw.js                 офлайн-кеш
icons/                иконка приложения (обычная и maskable)
```
